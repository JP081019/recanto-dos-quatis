# 4. HERO CINEMATOGRÁFICO 3D

Esta é a parte mais importante do projeto.

## Objetivo

Criar uma floresta tridimensional REAL, com geometria, profundidade, iluminação e movimento de câmera.

A floresta será renderizada previamente.

O navegador não deverá precisar renderizar todo o ambiente 3D em tempo real.

## Ferramentas

Utilizar conforme necessidade:

- Three.js para construção programática da cena 3D.
- Blender, caso esteja disponível e seja tecnicamente vantajoso.
- Remotion para composição e finalização cinematográfica.
- FFmpeg para processamento e otimização.
- GSAP ScrollTrigger para controle da animação.
- Canvas para exibição dos frames.

Não confundir uma composição de fotografias com uma floresta tridimensional real.

A cena deve possuir geometria 3D verdadeira.

## Cenário

Criar uma floresta cinematográfica com:

- Árvores em diferentes profundidades.
- Troncos e galhos.
- Folhagens.
- Vegetação próxima ao solo.
- Terreno natural.
- Caminho visual para a câmera.
- Iluminação quente de início da manhã.
- Névoa atmosférica.
- Sombras naturais.
- Profundidade de campo, se viável.

A vegetação deve ser visualmente convincente.

Evitar aparência de jogo antigo, low-poly evidente ou cenário artificial.

Priorizar qualidade cinematográfica dentro dos recursos disponíveis.

## Movimento de câmera

A câmera deverá percorrer uma trajetória previamente definida.

O movimento deve ser suave e elegante, como uma tomada cinematográfica.

Evitar rotações bruscas, movimentos excessivos e alterações repentinas de velocidade.

O movimento deve ser preparado para funcionar tanto para frente quanto para trás, conforme a rolagem.

# 5. STORYBOARD DA ANIMAÇÃO

## Cena 01 — O chamado da natureza

Progresso: 0%–20%.

A floresta ocupa toda a tela.

A câmera permanece quase estática.

A iluminação atravessa suavemente a vegetação.

Exibir:

**RECANTO DOS QUATIS**

Frase:

**O extraordinário está em desacelerar.**

Adicionar indicador discreto de rolagem.

## Cena 02 — A jornada

Progresso: 20%–45%.

A câmera começa a avançar pela floresta.

Árvores e folhagens passam pelas laterais.

A perspectiva cria profundidade real.

O título desaparece suavemente.

A iluminação se transforma gradualmente.

## Cena 03 — A descoberta

Progresso: 45%–70%.

A vegetação começa a se abrir.

A câmera se aproxima de uma clareira.

Uma fotografia real da hospedagem começa a aparecer.

Integrar a fotografia à composição utilizando perspectiva, máscaras e movimento.

Não utilizar uma troca brusca de imagem.

## Cena 04 — A revelação

Progresso: 70%–90%.

A fotografia real assume progressivamente o enquadramento.

Os elementos tridimensionais desaparecem.

A fotografia se torna protagonista.

A transição deve parecer uma continuidade do movimento da câmera.

## Cena 05 — Bem-vindo ao Recanto

Progresso: 90%–100%.

A fotografia real ocupa a tela.

Exibir:

**Seu próximo refúgio começa aqui.**

Adicionar CTA:

**Conheça o Recanto**

A animação termina e a navegação continua naturalmente.

# 7. PROCESSAMENTO COM FFMPEG

Utilizar FFmpeg para:

- Processar os materiais renderizados.
- Gerar sequências de frames.
- Redimensionar arquivos.
- Comprimir imagens.
- Criar versões específicas para desktop e mobile.
- Gerar vídeo demonstrativo, caso necessário.

## Parâmetros iniciais

Duração cinematográfica: aproximadamente 6 segundos.

Taxa de quadros: 30 fps.

Quantidade inicial: 180 frames.

Resolução de referência desktop: até 1920 × 1080.

Criar uma versão adaptada para mobile.

Esses valores não são obrigatórios caso os testes indiquem alternativas melhores.

Priorizar o equilíbrio entre qualidade e desempenho.

Não exportar centenas de imagens enormes sem estratégia de compressão.

Avaliar WebP, AVIF ou outros formatos adequados.

Evitar carregar todos os frames simultaneamente em dispositivos com pouca memória.

# 8. CONTROLE POR SCROLL

Implementar a sequência utilizando GSAP ScrollTrigger.

## Comportamento

- O progresso da rolagem controla o frame exibido.
- Rolagem para baixo avança a sequência.
- Rolagem para cima retrocede.
- O hero permanece fixado durante a sequência cinematográfica.
- A transição para a próxima seção deve ser natural.
- Não utilizar scroll artificial no website inteiro.
- Não bloquear a navegação do usuário.

## Renderização

Utilizar Canvas para desenhar os frames.

Implementar:

- Carregamento progressivo.
- Pré-carregamento inteligente.
- Cache limitado.
- Tratamento de frames ainda não disponíveis.
- Redimensionamento responsivo.
- Tratamento de erros.
- Limpeza de recursos.
- Fallback estático.

O primeiro conteúdo visual deve aparecer rapidamente.

Não deixar o visitante diante de uma tela preta enquanto os arquivos carregam.

## Performance

Utilizar `requestAnimationFrame` quando apropriado.

Evitar renderizações desnecessárias do React durante a rolagem.

Gerenciar a memória utilizada pelas imagens.

Testar o comportamento em dispositivos móveis.

Respeitar `prefers-reduced-motion`.
